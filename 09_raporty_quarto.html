10  Raporty reprodukowalne w Quarto

Raporty tworzenone w Quarto to dokument który łączy kod, wyniki i narrację w jedną spójną całość, którą można przekazać innym. Quarto pozwala tworzyć takie raporty automatycznie — zmieniasz dane, klikasz Render i masz aktualny dokument.

NoteCzym jest raport reprodukowalny?

Tradycyjny raport powstaje w dwóch krokach: analizujesz dane w R, kopiujesz wyniki do Worda. Gdy dane się zmieniają — musisz robić to od nowa, ręcznie. Błędy są nieuniknione.

Raport reprodukowalny to jeden dokument który zawiera i kod, i tekst. Quarto wykonuje kod automatycznie przy każdym renderowaniu — wyniki, tabele i wykresy zawsze odpowiadają aktualnym danym. Nie ma kopiowania, nie ma rozbieżności.

10.1 Struktura dokumentu Quarto

Każdy plik .qmd składa się z trzech elementów:

---
# 1. NAGŁÓWEK YAML — ustawienia dokumentu
title: "Mój raport"
format: html
---

# 2. TEKST — narracja w formacie Markdown

Tutaj piszesz zwykły tekst, nagłówki, listy...

# 3. KOMÓRKI KODU — wykonywalny kod R lub Python


::: {.cell}

```{.r .cell-code}
1 + 1
#> [1] 2

:::


Przyjrzyjmy się każdemu elementowi z osobna.

---

## Nagłówek YAML {#sec-yaml}

Nagłówek YAML to sekcja między `---` na początku pliku. Określa metadane dokumentu i sposób jego renderowania.

### Podstawowy nagłówek

```yaml
---
title: "Analiza wskaźników makroekonomicznych Polski"
subtitle: "Raport kwartalny"
author: "Jan Kowalski"
date: today
lang: pl
format: html
---
Tip

date: today automatycznie wstawia aktualną datę przy każdym renderowaniu — nie musisz jej aktualizować ręcznie.

Format HTML

Format HTML jest domyślnym i najbogatszym formatem Quarto — obsługuje interaktywność, zakładki, rozwijane sekcje i wiele innych.

---
title: "Analiza wskaźników makroekonomicznych Polski"
author: "Jan Kowalski"
date: today
lang: pl
format:
  html:
    toc: true                  # spis treści
    toc-depth: 3               # głębokość spisu (nagłówki H1–H3)
    toc-title: "Spis treści"
    number-sections: true      # numerowanie rozdziałów
    theme: cosmo               # motyw wizualny
    embed-resources: true      # jeden plik HTML (bez zewnętrznych zasobów)
    code-fold: true            # kod domyślnie zwinięty
    code-summary: "Pokaż kod"  # etykieta przycisku rozwijającego kod
    fig-width: 7               # domyślna szerokość wykresów (cale)
    fig-height: 4.5            # domyślna wysokość wykresów (cale)
---
Importantembed-resources: true — jeden plik HTML

Domyślnie Quarto generuje plik HTML + folder z zasobami (CSS, JS, obrazki). Opcja embed-resources: true osadza wszystko w jednym pliku — możesz go wysłać e-mailem lub udostępnić bez obawy że coś się rozjedzie.

Format DOCX (Word)

---
title: "Analiza wskaźników makroekonomicznych Polski"
author: "Jan Kowalski"
date: today
lang: pl
format:
  docx:
    toc: true
    toc-depth: 3
    number-sections: true
    fig-width: 6               # w DOCX mniejsze wykresy — kolumna tekstu A4
    fig-height: 4
    reference-doc: szablon.docx   # opcjonalnie: własny szablon Word
---
TipWłasny szablon Word

Jeśli Twoja uczelnia wymaga określonego formatowania (czcionka, marginesy, nagłówki), możesz stworzyć szablon Word i wskazać go w reference-doc. Quarto przejmie stamtąd style formatowania.

Aby wygenerować szablon do modyfikacji:

quarto pandoc -o szablon.docx --print-default-data-file reference.docx

Dwa formaty jednocześnie

---
title: "Analiza wskaźników makroekonomicznych Polski"
author: "Jan Kowalski"
date: today
lang: pl
format:
  html:
    toc: true
    embed-resources: true
    code-fold: true
  docx:
    toc: true
    fig-width: 6
---

Renderowanie: quarto render raport.qmd — Quarto wygeneruje oba pliki naraz.

Globalne ustawienia wykonywania kodu

execute:
  echo: false       # nie pokazuj kodu w raporcie (tylko wyniki)
  warning: false    # ukryj ostrzeżenia
  message: false    # ukryj komunikaty (np. przy wczytywaniu pakietów)
Note

Ustawienie echo: false w sekcji execute wyłącza wyświetlanie kodu globalnie — idealne dla raportów dla odbiorców nieznających R. Możesz je nadpisać w konkretnej komórce ustawiając #| echo: true.

10.2 Tekst w formacie Markdown

Treść raportu piszesz w Markdown — prostym języku znaczników. Poniżej najważniejsze elementy.

Nagłówki i struktura

# Rozdział 1 — nagłówek poziomu 1

## Podrozdział 1.1 — nagłówek poziomu 2

### Sekcja 1.1.1 — nagłówek poziomu 3

Formatowanie tekstu

**pogrubienie**
*kursywa*
***pogrubiona kursywa***
`kod inline` — np. nazwa funkcji `mean()` lub pakietu `ggplot2`
~~przekreślenie~~

Wynik: pogrubienie, kursywa, pogrubiona kursywa, kod inline, przekreślenie

Listy

Lista nieuporządkowana:
- pierwszy element
- drugi element
  - element zagnieżdżony

Lista numerowana:
1. krok pierwszy
2. krok drugi
3. krok trzeci

Tabele w Markdown

| Kraj      | PKB (mld USD) | Inflacja (%) |
|-----------|--------------|-------------|
| Polska    | 688          | 11.4        |
| Niemcy    | 4 072        | 5.9         |
| Francja   | 2 782        | 5.2         |
Tip

Tabele w czystym Markdown są dobre dla prostych, statycznych zestawień. Do tabel generowanych z danych R używamy pakietu knitr lub gt — opisanych w Section 10.4.

Callout boxes

Quarto oferuje specjalne bloki wyróżniające — przydatne do podkreślenia ważnych informacji:

::: {.callout-note}
Notatka — dodatkowa informacja
:::

::: {.callout-tip}
Wskazówka — praktyczna rada
:::

::: {.callout-important}
Ważne — informacja krytyczna
:::

::: {.callout-warning}
Ostrzeżenie

Równania matematyczne

Quarto obsługuje zapis równań w LaTeX — zarówno w tekście jak i w osobnych blokach:

Równanie w tekście: $\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i$

Równanie w osobnym bloku:
$$
\text{PKB} = C + I + G + (X - M)
$$

Wynik (blok): \[\text{PKB} = C + I + G + (X - M)\]

10.3 Komórki kodu

Komórka kodu to blok otoczony potrójnymi apostrofami z oznaczeniem języka w klamrach:


::: {.cell}

```{.r .cell-code}
# kod R
mean(c(1, 2, 3, 4, 5))
```

::: {.cell-output .cell-output-stdout}

```
#> [1] 3
```


:::
:::

Opcje komórki

Opcje komórki kontrolują jak kod i jego wyniki są wyświetlane w dokumencie. Zapisujesz je wewnątrz komórki, poprzedzone #|:

Najważniejsze kombinacje opcji

Cel Opcje
Tylko wynik, bez kodu echo: false
Tylko kod, bez wykonywania eval: false
Ani kodu ani wyniku (kod pomocniczy) include: false
Kod widoczny, ale nie wykonany eval: false, echo: true
Wykres z podpisem fig-cap: "...", label: fig-...

Komórka setup — wczytywanie pakietów

Dobrą praktyką jest umieszczenie wszystkich library() i wczytywania danych w jednej komórce na początku dokumentu z opcją include: false:

Wyniki inline — wartości w tekście

Quarto pozwala wstawiać wyniki obliczeń bezpośrednio do tekstu narracji. Dzięki temu liczby w tekście zawsze odpowiadają aktualnym danym:

Średnia inflacja w analizowanym okresie wyniosła
4.3%.
Maksimum osiągnięto w roku 2022,
kiedy inflacja wyniosła 14.4%.

Wynik w dokumencie:

Średnia inflacja w analizowanym okresie wyniosła 4.3%. Maksimum osiągnięto w roku 2022, kiedy inflacja wyniosła 14.4%.

ImportantTo jest kluczowa zaleta raportów reprodukowalnych

Gdy dane się zaktualizują — liczby w tekście zaktualizują się automatycznie przy kolejnym renderowaniu. Nie musisz niczego szukać i poprawiać ręcznie.

10.4 Tabele

Tabele z knitr::kable()

Funkcja kable() zamienia ramkę danych R na sformatowaną tabelę w dokumencie. Działa poprawnie w HTML i DOCX.

library(knitr)

dane |>
  kable(
    col.names = c("Rok", "PKB (mld PLN)",
                  "Inflacja (%)", "Bezrobocie (%)"),
    digits    = 1,
    align     = c("c", "r", "r", "r"),
    format.args = list(big.mark = " ")
  )

Tabele z kableExtra — zaawansowane formatowanie

Pakiet kableExtra rozszerza kable() o dodatkowe opcje: kolorowanie wierszy, grupowanie nagłówków, pogrubienie komórek.

library(kableExtra)

dane |>
  kable(
    col.names = c("Rok", "PKB (mld PLN)",
                  "Inflacja (%)", "Bezrobocie (%)"),
    digits    = 1,
    align     = c("c", "r", "r", "r"),
    format.args = list(big.mark = " ")
  ) |>
  kable_styling(
    bootstrap_options = c("striped", "hover", "condensed"),
    full_width        = FALSE,
    position          = "center"
  ) |>
  column_spec(3,                           # kolumna Inflacja
    bold  = dane$inflacja > 5,             # pogrub gdy > 5%
    color = ifelse(dane$inflacja > 5,
                   "white", "black"),
    background = ifelse(dane$inflacja > 5,
                        "#d62728", "transparent")
  ) |>
  row_spec(0, bold = TRUE, background = "#f0f0f0") |>  # nagłówek
  add_header_above(
    c(" " = 1, "Dane makroekonomiczne" = 3)
  )
TipkableExtra w DOCX

Opcje bootstrap_options działają tylko w HTML — w DOCX są ignorowane. Formatowanie warunkowe (column_spec, row_spec) działa w obu formatach. Jeśli renderujesz jednocześnie do HTML i DOCX, możesz warunkowo dostosować styl:

fmt <- if (knitr::is_html_output()) "html" else "latex"

Tabele z gt — formatowanie warunkowe

Pakiet gt oferuje bardziej rozbudowane opcje formatowania, szczególnie przydatne w HTML. Poniżej przykład z formatowaniem warunkowym:

library(gt)

dane |>
  gt() |>
  cols_label(
    rok        = "Rok",
    PKB        = "PKB (mld PLN)",
    inflacja   = "Inflacja (%)",
    bezrobocie = "Bezrobocie (%)"
  ) |>
  fmt_number(columns = PKB,        decimals = 0, sep_mark = " ") |>
  fmt_number(columns = c(inflacja, bezrobocie), decimals = 1) |>
  # Formatowanie warunkowe — tło kolumny inflacja
  data_color(
    columns = inflacja,
    method  = "numeric",
    palette = c("white", "#ff9999", "#d62728"),
    domain  = c(min(dane$inflacja), max(dane$inflacja))
  ) |>
  tab_header(
    title    = "Wskaźniki makroekonomiczne Polski",
    subtitle = "Lata 2015–2024"
  ) |>
  tab_source_note("Źródło: GUS | Dane ilustracyjne") |>
  tab_style(
    style     = cell_text(weight = "bold"),
    locations = cells_column_labels()
  )
Notekable vs gt — kiedy co używać?
kable + kableExtra gt
Prostota bardzo prosta więcej kodu
HTML dobry bardzo dobry
DOCX dobry ograniczony
Formatowanie warunkowe dobry rozbudowane
Wykresy w komórkach brak (gt_sparkline)

Dla raportów generowanych jednocześnie do HTML i DOCX — kable + kableExtra. Dla raportów tylko HTML gdzie zależy Ci na efekcie wizualnym — gt.

10.5 Odnośniki i cytowania

Odnośniki do elementów dokumentu

Quarto automatycznie tworzy odnośniki do elementów z etykietą (label). Konwencja nazewnictwa:

  • fig- — wykresy (np. #| label: fig-inflacja)
  • tbl- — tabele (np. #| label: tbl-pkb)
  • sec- — sekcje (np. {#sec-wstep})

W tekście odwołujesz się przez @etykieta:

Jak pokazano na @fig-inflacja, inflacja w 2022 roku osiągnęła rekordowy poziom.

Szczegółowe dane przedstawia @tbl-podstawowa.

Metodologia opisana jest w @sec-dane.

Quarto automatycznie wstawi “Rysunek 1”, “Tabela 2”, “Rozdział 3” — w odpowiednim języku jeśli ustawisz lang: pl w YAML.

Cytowania bibliograficzne — styl APA

Cytowania w Quarto obsługiwane są przez plik .bib (BibTeX). Workflow:

Krok 1 — utwórz plik bibliografia.bib w folderze projektu:

@book{woźniak2020,
  author    = {Woźniak, Michał Gabriel},
  title     = {Gospodarka Polski},
  year      = {2020},
  publisher = {PWN},
  address   = {Warszawa}
}

@article{kowalski2023,
  author  = {Kowalski, Jan and Nowak, Anna},
  title   = {Inflacja w Polsce w latach 2020--2023},
  journal = {Gospodarka Narodowa},
  year    = {2023},
  volume  = {314},
  number  = {2},
  pages   = {45--67},
  doi     = {10.33119/GN/163704}
}

@misc{gus2024,
  author = {{Główny Urząd Statystyczny}},
  title  = {Wskaźniki makroekonomiczne},
  year   = {2024},
  url    = {https://stat.gov.pl},
  note   = {Dostęp: 2024-12-01}
}

Krok 2 — wskaż plik w nagłówku YAML:

---
title: "Analiza wskaźników makroekonomicznych"
bibliography: bibliografia.bib
csl: apa.csl          # plik ze stylem cytowań
lang: pl
---
TipPlik CSL dla stylu APA

Plik apa.csl definiuje formatowanie cytowań. Pobierz go ze strony zotero.org/styles (wyszukaj “apa”) i umieść w folderze projektu obok pliku .qmd.

Quarto obsługuje tysiące stylów cytowań z repozytorium CSL — możesz użyć dowolnego stylu wymaganego przez wydawnictwo lub uczelnię.

Krok 3 — cytuj w tekście:

Wzrost inflacji w Polsce był powiązany z globalnymi zaburzeniami podaży
[@kowalski2023]. Szczegółowe dane makroekonomiczne dostępne są
w publikacjach GUS [-@gus2024].

Jak zauważa @woźniak2020 [s. 142], gospodarka polska...

Wyniki w stylu APA:

  • [@kowalski2023] → (Kowalski & Nowak, 2023)
  • [-@gus2024] → (2024) — bez nazwiska autora
  • @woźniak2020 [s. 142] → Woźniak (2020, s. 142)

Krok 4 — lista bibliograficzna

Quarto automatycznie dodaje sformatowaną listę bibliograficzną na końcu dokumentu. Możesz wskazać jej miejsce przez:

## Literatura

::: {#refs}
:::
TipZotero — zarządzanie bibliografią

Jeśli używasz programu Zotero do zarządzania literaturą, możesz eksportować pozycje bezpośrednio do pliku .bib (prawy klik na kolekcję → Eksportuj → BibTeX). RStudio ma też integrację z Zotero — pozwala wyszukiwać i wstawiać cytowania bez opuszczania edytora.

10.7 Najczęstsze problemy i rozwiązania

Problem Przyczyna Rozwiązanie
Raport się nie renderuje Błąd w kodzie R Sprawdź konsolę — Quarto podaje numer linii błędu
Wykres nie pojawia się eval: false lub błąd w kodzie Sprawdź czy kod działa w konsoli osobno
Polskie znaki wyświetlają się źle Kodowanie pliku Zapisz plik jako UTF-8 (w RStudio: File → Save with Encoding)
Tabela wychodzi poza margines w DOCX Za dużo kolumn Zmniejsz czcionkę tabelki lub usuń kolumny
Cytowanie nie pojawia się Zła etykieta w .bib Sprawdź czy etykieta w @etykieta dokładnie odpowiada kluczowi w pliku .bib
Spis treści nie działa w DOCX Brak nagłówków H1–H3 Upewnij się że używasz #, ##, ###
Wyniki inline pokazują błąd Obiekt nie istnieje Sprawdź czy komórka setup jest wykonana (include: false, nie eval: false)
